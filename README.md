# explainer-films

Narrated, interactive learning films built with the `explainer-film` skill.

- Skill: `.claude/skills/explainer-film/` (Claude Code project skill), symlinked at `.agents/skills/explainer-film` (Codex repo skill)
- Films: `films/<slug>/` (story.js, voice.json, vo.json, vo/*.mp3, index.html)

Build a film: see `.claude/skills/explainer-film/SKILL.md`.
